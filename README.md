# Tea House with DaisyUI

🌟 **Live Demo:** [https://newbie-saimur.github.io/tea-house-with-daisyui/](https://newbie-saimur.github.io/tea-house-with-daisyui/)

A modern, responsive tea house website built with HTML, Tailwind CSS, and DaisyUI. This project showcases a beautiful tea house landing page with elegant design, smooth animations, and mobile-first responsive layout.

## 🍵 Features

- **Responsive Design**: Mobile-first approach ensuring perfect display across all devices
- **Modern UI Components**: Built with DaisyUI for consistent and beautiful components
- **Fast Loading**: Optimized images and efficient CSS for quick page loads
- **Clean Typography**: Uses Google Fonts (Manrope) for elegant text presentation
- **Interactive Elements**: Hover effects and smooth transitions
- **Trust Pilot Integration**: Displays customer ratings and reviews
- **Newsletter Signup**: User engagement through email subscription
- **Product Showcase**: Beautiful tea product gallery
- **Customer Testimonials**: Social proof section with customer reviews

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for better accessibility
- **CSS3**: Custom styles and animations
- **Tailwind CSS**: Utility-first CSS framework for rapid development
- **DaisyUI**: Component library built on top of Tailwind CSS
- **Google Fonts**: Manrope font family for typography
- **Responsive Images**: Optimized image assets

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic understanding of HTML, CSS, and Tailwind CSS

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/newbie-saimur/tea-house-with-daisyui.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd tea-house-with-daisyui
   ```

3. **Open the project**
   - Simply open `index.html` in your web browser
   - Or use a local development server like Live Server in VS Code

### Development Setup

If you want to modify the Tailwind configuration:

1. **Install dependencies** (if you want to customize Tailwind)
   ```bash
   npm install
   ```

2. **Start development**
   - The project uses CDN links for Tailwind CSS and DaisyUI for simplicity
   - No build process required for basic usage

## 🎨 Design Features

### Color Scheme
- **Primary Colors**: Elegant greens and earth tones reflecting tea culture

### Typography
